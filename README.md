# Unsupervised Learning: Clustering

This project explores customer/data segmentation using K-Means and Hierarchical Clustering in Python.

## What I worked on

- Applied K-Means clustering and used the Elbow Method to explore the number of clusters.
- Evaluated clustering results using Silhouette Scores.
- Applied Hierarchical Clustering and visualised the results using a dendrogram.
- Compared clustering approaches and feature-scaling methods.

## Tools used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Files

- `unsupervised_learning_clustering.ipynb` — notebook containing the analysis.
- `KMeans_Hierarchical_Clustering_Data.xlsx` — dataset used for the project.
